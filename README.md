# Система модерации объявлений

Веб‑приложение для модераторов Авито: просмотр списка объявлений, модерация (одобрение/отклонение/доработка), bulk операции и статистика работы модератора.

---

## Запуск проекта

```bash
# Переход в директорию проекта
cd avito-ad-moderation

# Запуск
docker compose up

```

Приложение будет доступно по адресу: `http://localhost:80`

## Стек технологий

- React 19, Vite, TypeScript, React Router v7
- Tanstack Query, Zustand
- Material UI
- Motion (бывший framer motion)
- Vitest + Testing Library

## Архитектура

Архитектура проекта представляет из себя облегченную версию FSD. Такой выбор был сделан из-за того, что она остается гибкой, понятной и расширяемой

```bash
src/
  app/                 # Входные точки, провайдеры, роутер
  pages/               # Страницы по роутам и специфичные им их хуки/компоненты (list, item, stats)
  features/            # Фичи (ad-filters, ad-moderation, ui-theme-switch)
  entities/            # Доменные сущности (ad, moderator, stats)
  shared/              # Общие утилиты, конфиги, UI
    api/               # axios-клиент (в будущем другие клиенты, middleware)
    components/        # инфраструктурные компоненты (ErrorBoundary)
    config/            # конфиги проекта (queryClient, apiConfig, тесты)
    lib/               # хелперы, хуки
    pdf/               # утилиты для экспорта в PDF
    ui/                # переиспользуемые ui компоненты

```

## Особенности реализации

В проекте выполнены все основные и дополнительные пункты задания. Что сделано, но не было в тз:

- Адаптация интерфейса до 375px
- Заготовка под расширение проекта (сущность moderator, лк модератора)

### То, что получилось хорошо и решает бизнес-задачу

- Навигация между объявлениями на странице объявления (task/{id}) производится в контексте отфильтрованного списка, который определил пользователь, но не ограничивается размером пагинации. Например, если пользователь выбрал статус "Одобрено" и нашлось всего 32 (10 на странице) - то провалившись в любое объявление он сможет бесшовно переходить по всем 32 объявлениям
- Реализованы все хоткеи
- Есть возможность локального сохранения наборов фильтров
- Синхронизация с url'ом и сохранение фильтров
- Статистика и экспорт отчетов (pdf, csv) по предопределенным (день, неделя, месяц) и произвольным периодам
- Оптимизация и UX

### Качество кода

- Используется eslint и prettier
- Часть важного функционала покрыта тестами
- Соблюдается модульность

### Что можно улучшить

- Есть базовая логика отображения новых объявлений при подгрузке новых данных, но сейчас они сразу выводятся в список с пометками (пункт про подсчет выполнен)
- В тз не было уточнений, но у действий модераторов должны быть (скорей всего), какие-то бизнес-правила (в каких случаях, какие действия доступны)
